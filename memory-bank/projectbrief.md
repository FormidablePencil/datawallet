# Project Brief: PaoValues

## Project Overview

**PaoValues** is a mnemonic PAO (Person-Action-Object) system for storing and sharing values using the major memory system technique. Each number from 00-99 is associated with a unique Person, Action, and Object, creating a memorable index system for storing various types of information.

## Core Purpose

The project provides a structured way to:
1. **Store PAO associations** - Maintain a complete set of 100 number-to-PAO mappings (00-99)
2. **Index values** - Use PAO associations as memorable addresses for storing conceptual values, visual elements, NFTs, or other data types
3. **Share systems** - Export and import PAO systems for collaboration and community sharing

## Project Goals

### Primary Goals
- Create a file-based PAO system that can store and retrieve values by number index
- Provide a complete, memorable set of 100 PAO associations (00-99)
- Enable sharing and exporting of PAO systems

### Secondary Goals
- Support multiple PAO systems (different users can have different associations)
- Practice/review mode for memorization
- Import/export functionality for data portability

## Scope

### In Scope
- File-based data storage for PAO associations
- JSON-based format for PAO system definitions
- CLI or simple interface for managing PAO entries
- Value storage at specific number indexes

### Out of Scope (for now)
- Full web application (to be built after file-based foundation)
- Mobile applications
- Complex database systems

## Success Criteria

1. Complete PAO system with all 100 entries (00-99) stored in files
2. Ability to store and retrieve values using number indexes
3. Export/import functionality for PAO systems
4. Clear documentation for the system
